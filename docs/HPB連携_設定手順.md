# HPB連携（予約メールの取り込み）設定手順

HPB（ホットペッパービューティー）の予約通知メールを、自社の予約台帳へ自動で入れるしくみです。
**取り込みだけ**です。サロンボードには何も書き込みません（枠を閉じる作業は今までどおり）。

```
サロンボード ──予約通知メール──▶ kokage.corp+hpb-◯◯@gmail.com（Gmail）
                                   │  Google Apps Script（5分ごと・無料）
                                   ▼
                     アプリの受け口 /api/inbound/hpb ──▶ 予約台帳（HPBの印）＋受信ログ
```

## 0. 先にやること（1回だけ）
1. Supabase の SQL エディタで `supabase/migrations/0011_hpb_inbound.sql` を流す（0010 の後）。最後に「0011 OK」と出れば完了。
2. Vercel → Settings → Environment Variables に **`SUPABASE_SERVICE_ROLE_KEY`** を入れる（Supabase → Settings → API の service_role key。人に見せない）。入れたら Redeploy。
   - 確認：ブラウザで `https://salon-app-alpha-seven.vercel.app/api/inbound/hpb` を開いて `"ok":true` と出ればOK（`not_configured` ならキーが入っていない）。

## 1. アプリ側（設定＞HPB連携＞つなぐ設定）
1. 「合言葉を作る」を押す → 表示された合言葉をコピー（**今だけ表示**。あとで見られません。人に見せない）。
2. 「サロンボードに登録するメールアドレス」を確認（例 `kokage.corp+hpb-kokage-gotanda@gmail.com`）。
3. 「取り込みのオン・オフ」にチェック。
4. 「対応表」タブで、HPBのクーポン名 → 自社メニューの対応を足す（同じ名前なら自動で合わせます。「試す」で確認できます）。

## 2. サロンボード側
1. サロンボード → 設定（店舗・サロン情報）→ **予約通知メールの送信先**（10件まで登録できる欄）に、上のアドレスを **1つ足す**。今のカミングスーンの受付アドレスは消さない。
2. 「+」付きのアドレスが登録できない場合は、窓口に連絡してください（別の方法：Gmail のフィルタで HPB からのメールに印を付ける形に変えます）。

## 3. Google Apps Script（kokage.corp の Gmail で）
1. https://script.google.com を **kokage.corp@gmail.com** で開く → 「新しいプロジェクト」→ 名前「HPB取り込み（◯◯店）」。
2. `tools/gas/hpb_forwarder.gs` の中身を全部貼り付けて保存。
3. 左の歯車「プロジェクトの設定」→ 下の「スクリプト プロパティ」に4つ入れる：

| プロパティ | 値 |
|---|---|
| WEBHOOK_URL | `https://salon-app-alpha-seven.vercel.app/api/inbound/hpb` |
| SECRET | 1-1 でコピーした合言葉 |
| QUERY | `to:kokage.corp+hpb-◯◯@gmail.com newer_than:2d`（◯◯は店ごと） |
| DRY_RUN | `true`（最初は試し） |

4. エディタ上の関数の選択で **`listOnly`** → 実行（初回は Google の許可画面が出るので「許可」）。条件に合うメールの件名がログに出ます。
5. **`testLatest`** → 実行。一番新しいメールを「試し」で送り、アプリがどう読んだか（予約番号・日時・名前…）がログに出ます。台帳には入りません。
6. 読み取りがおかしいときは、そのログ（本文の個人情報は消して）を窓口に送ってください。読み取りの調整をします。
7. 問題なければ DRY_RUN を **`false`** にして、**`installTrigger`** を1回実行 → 5分ごとに自動で動きます。
   - 止めたいとき：`removeTrigger` を実行、またはアプリの「取り込みのオン・オフ」を外す（届いたメールは受信ログに「無視」で残り、あとで「再処理」できます）。

## 4. テスト店舗で試す（HPBが無くても試せる）
設定＞HPB連携＞**テスト**（テスト店舗・オーナーだけ）→「テストメールを送る」。
本物と同じ処理で台帳に入ります。新規 → 変更 → キャンセル、ペアのクーポン、空きが無い時間（赤い印）を試せます。

## 5. ふだんの見かた
- 予約台帳：HPBの予約は「HPB」の印。空きが足りないのに入った予約は **赤い枠＋「⚠重複」**。上に「⚠ ダブルブッキングの可能性 ◯件」。予約を押して担当・時間を調整 →「調整した（印を消す）」。
- 予約台帳の「新しい予約 ◯件」ボタン：HPBの新規・変更・キャンセルと、自動で読めなかったメール（HPB要確認）が出ます。
- 設定＞HPB連携＞**受信ログ**：届いたメールすべて・読み取った内容・やったこと。「要確認（未取込）」は **手で直す**（日時・予約番号・メニューなどを入れて反映）か **再処理**。

## 6. 注意
- 本物のHPBのメールの形は、まだ確かめていません。**最初の本物のメールが届いたら、受信ログで読み取り結果を必ず確認**してください。読めない項目があれば、つなぐ設定の「読み取りの調整」に言葉を足すか、窓口に本文を送ってください。
- メールが届いてから台帳に入るまで、最大5分ほどかかります（Apps Script の間隔）。その間にネット予約・電話予約で同じ時間が埋まることがあります（そのときは赤い印が付きます）。
- 台帳でHPBの予約を変えても、HPB（サロンボード）には反映されません。
- 合言葉が漏れた疑いがあるときは「合言葉を作り直す」→ Apps Script の SECRET を入れ直す。
