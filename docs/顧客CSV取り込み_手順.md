# 顧客CSV取り込みの手順（サロンアンサー・カミングスーン → このアプリ）

いま使っているPOS（ラシエル大橋＝サロンアンサー、KOKAGE西五反田＝カミングスーン）のお客様の名簿と来店履歴を、このアプリに取り込む手順です。
取り込みは **オーナー・店長だけ** ができます。

> ⚠ **要確認**：サロンアンサー・カミングスーンの「書き出し（エクスポート）」の画面は、まだ実物を見ていません。下の「書き出し方」は一般的な手順です。
> 実際の画面と違うところがあれば、書き出したCSVを1つ送ってください。列の対応（見出し→項目）をそのPOS用に合わせて保存します。

---

## 0. はじめに（1回だけ）

1. Supabase の SQL Editor で **0011 → 0012 の順に** Run（`supabase/migrations/0012_customer_import.sql`）。
   0011 が未実行のまま 0012 を流すと、最初で止まります（DBは何も変わりません）。
2. アプリを再読み込みすると、**設定 ＞ 顧客CSV取り込み** が使えるようになります（それまでは「準備中」と表示）。

## 1. 前のPOSからCSVを書き出す（要確認）

### サロンアンサー（ラシエル大橋）
- 管理メニューの「顧客管理」または「データ出力」系の画面から、**顧客一覧をCSVで出力**（顧客データのCSV出力ができることは確認済み）。
- 可能なら次の列を含めてください：顧客番号／氏名／フリガナ／電話（携帯）／メール／生年月日／性別／郵便番号・住所／初回来店日／最終来店日／来店回数／担当／メモ。
- 来店履歴（売上明細・来店記録）もCSVで出せる場合は、来店日／顧客番号／担当／メニュー／金額／伝票番号 の列があると、来店履歴として取り込めます。
- 文字コードは Shift_JIS（Windows の CP932）のことが多いですが、アプリが自動で判定します。

### カミングスーン（KOKAGE西五反田）
- 管理画面の「顧客」一覧から **CSVダウンロード／エクスポート**（メニュー名は要確認）。
- 姓・名、セイ・メイが別の列でも、アプリでつなげて取り込めます。
- 予約・来店の履歴が出せる場合は、来店履歴として取り込めます。

> 書き出したファイルには個人情報が入っています。**メールやLINEで送らず**、取り込みが終わったらパソコンから削除してください。

## 2. 顧客を取り込む

1. **設定 ＞ 顧客CSV取り込み ＞「顧客」**。取り込み元（サロンアンサー／カミングスーン／その他）を選ぶ。
2. **CSVファイルを選ぶ**。行数・列数と文字コード（自動判定）が出ます。文字化けしていたら文字コードを切り替える。
3. **列の対応を確かめる**。見出しの言葉から自動で選んでいます（氏名・フリガナ・電話・メール・生年月日・性別・郵便番号・住所・初回来店日・最終来店日・来店回数・担当・顧客番号・メモ）。違うところだけ直し、「この対応を保存」を押すと、次から同じPOSのCSVは自動でその対応になります。
4. **すでに登録されている人と同じだったとき** を選ぶ：
   - **空欄だけ埋める（おすすめ）**：今入っている値は変えません。
   - **CSVの内容で上書き**：CSVの値で置きかえます（メモは書き足し）。
5. **下見する**（まだ取り込みません）。1行ずつ次のどれかになります：
   - 新しく登録／更新（どの項目を変えるか表示）／変更なし／重複でスキップ（同じファイルの上の行と同じ人）／エラー（氏名もフリガナも空 など）
   - 同じ人かどうかは ①同じ取り込み元の顧客番号 → ②電話番号 → ③フリガナと氏名がどちらも同じ、の順で探します。
6. **取り込む**。進み具合が出ます。終わったら件数が表示されます。

- 同じファイルをもう一度取り込んでも **二重にはなりません**（顧客番号・電話で同じ人と分かるため「変更なし」になります）。
- 途中で止まったときも、同じファイルをもう一度取り込めば続きから入ります。

## 3. 来店履歴を取り込む（任意）

1. 先に「顧客」を取り込んでおく（顧客番号・電話でお客様を探すため）。
2. **設定 ＞ 顧客CSV取り込み ＞「来店履歴」** で同じようにファイル → 列の対応 → 下見 → 取り込む。
3. 取り込んだ来店は **「前のPOSの来店」** として別に保存します：
   - **売上台帳・集計・経理日別売上集計には入りません**（売上が二重にならないように）。
   - **新規／再来の判定**、ネット予約の **「新規限定」「前回来店から○日以内」クーポン**、お客様画面の **最終来店日** には使います。
   - 顧客CSVの「初回来店日・最終来店日・来店回数」も同じ扱いです（来店履歴CSVが無くても、新規／再来の判定は正しくなります）。

## 4. 取り消し

**「取り込みの記録」** に、いつ・誰が・どのファイルを・何件取り込んだかが残ります。
「この取り込みを取り消す」を押すと：
- その取り込みで **新しく登録した人のうち、まだ予約・会計・カルテが無い人** を消します（予約などがある人は残します）。
- その取り込みで入れた **来店履歴** を消します。
- **更新した人の項目は元に戻りません**（空欄だけ埋める、にしておけば元の値は残っています）。

## 5. 練習（デモ・テスト用のサンプル）

`tools/import-samples/` に架空の人のサンプルCSVがあります（本物のお客様ではありません）。
- `サンプル_サロンアンサー風_顧客_CP932.csv`（Shift_JIS。引用符・改行入りのメモ、和暦の生年月日、半角カナ、+81の電話、重複・エラーの行を含む）
- `サンプル_カミングスーン風_顧客_UTF8.csv`（UTF-8 BOMつき。姓・名・セイ・メイが別の列）
- `サンプル_サロンアンサー風_来店履歴_CP932.csv`（同じ伝票に2行、見つからないお客様、日付が空の行を含む）

## 6. 安全のための決まり

- お客様の中身はブラウザの中だけで読み、アプリのログ（画面の裏の記録・サーバの記録）には出しません。DBに入るのはお客様の項目と取り込みの件数だけです。
- 取り込み・記録・取り消し・列の対応の保存は、DB側でも **オーナー・店長だけ** に制限しています（0012 の RLS）。
- 前のPOSの来店は、スタッフも見られます（会計画面の新規／再来の表示に使うため）。
