# 止まったときの手順（店舗用・1枚）

アプリやネットが止まっても、**営業は続けます**。紙で受けて、直ってから入力します。あわてなくて大丈夫です。

## 毎朝やっておくこと（1分）

□ 予約台帳の「今日」と「明日」を、スマホでスクリーンショット（または印刷）しておく
　→ 止まっても、だれが何時に来るかが分かります

## 止まったら

### 1. まず確かめる（1分）

□ 店の Wi-Fi が切れていないか（スマホの4Gで同じ画面を開いてみる）
□ 4Gなら開く → 店のネットの問題。スマホのテザリングで続ける
□ 4Gでも開かない → アプリの問題。下の「紙で続ける」へ

### 2. 紙で続ける

| 場面 | すること |
|---|---|
| 来店 | 朝のスクリーンショットで確認。分からなければ、お名前とご予約の時間を聞く |
| 新しい予約（電話・店頭） | **紙の予約表**に書く：日付／時間／お名前／電話番号／メニュー／担当／受けた人 |
| 会計 | **手書きの伝票**に書く：時間／お名前／メニュー・店販／金額／支払い方法（現金・カード・QR）／担当。レシートが要る方には手書きの領収書 |
| カルテ | 紙のメモに書く（デザイン・本数・気づいたこと）。直ってから入力 |
| 同意書 | 紙の同意書に署名をもらう（引き出しに予備を置いておく） |

### 3. 止まっているものごとの対応

| 止まったもの | お客様への影響 | 対応 |
|---|---|---|
| アプリ全体 | LINE からの予約ができない | ホットペッパーと電話で受ける。LINE で聞かれたら「お電話でお願いします」 |
| LINE だけ | 予約ページが開かない・前日の確認が届かない | 明日の予約のお客様に、電話で確認する |
| ホットペッパーの取り込みだけ | ホットペッパーの予約が台帳に出ない | **サロンボードを正**にして、台帳に手で入れる |

### 4. 連絡する

□ 社長に LINE か電話：「いつから」「何が開かないか」「画面の文字（写真）」
□ お客様の情報・画面の写真は、社長以外に送らない

## 直ったら

□ 紙の予約表 → 台帳に入れる（電話予約として）
□ 手書きの伝票 → 会計に入れる（日付をその日に）
□ 紙のカルテ → カルテに入れる。紙の同意書 → 写真を撮ってカルテに置く
□ **二重予約がないか**、台帳とサロンボードを見比べる（止まっていた時間の前後）
□ 入れ終わった紙は、鍵のかかる場所へ（お客様の情報なので、捨てるときはシュレッダー）
□ 社長に「何時から何時まで止まっていた・紙で受けた件数」を伝える
