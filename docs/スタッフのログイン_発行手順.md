# スタッフのログイン 発行手順（オーナー向け）

スタッフ一人ひとりに「自分のログイン」を作ります。スマホからでも使えます。
ログインを作れるのは **オーナーだけ** です（店長は「状態を見る」「止める」だけ）。

---

## 最初に1回だけ（設定がまだの場合）

ログインの発行・停止はサーバで行います。Vercel に次の環境変数が入っていないと、画面に黄色い「サーバの設定がまだ」の表示が出て、発行できません。

| 環境変数 | 中身 | どこで見るか |
|---|---|---|
| `SUPABASE_SERVICE_ROLE_KEY` | Supabase のサービスキー（LINE連携で入れたものと同じ） | Supabase → Project Settings → API → `service_role` |
| `STAFF_INVITE_EMAIL_ENABLED`（任意） | `1` にすると「招待メールを送る」ボタンが出ます | メールの送信設定（SMTP）をした後だけ |

あわせて Supabase の DB更新 **0016_staff_login.sql** を流してください（0015 の後）。流さなくても動きますが、流すと「止めた人がすぐ締め出される」ようになります。

Supabase の Authentication → Sign In / Providers で **「Allow new users to sign up（新規登録を許可）」はオフ** のままにしてください（ログインはこの画面からだけ作る）。

---

## ログインを発行する

1. 設定 → スタッフ → そのスタッフの名前を押す
2. 下の「ログイン」欄にメールアドレスを入れる
   - 本人のメール（個人のGmailなど）でOK
   - **自分のメールが無い・教えたくない人** は「お店のGmail＋名前」が使えます
     例：お店のGmailが `kokage.store@gmail.com` なら `kokage.store+takesue@gmail.com`
     （届くメールはお店のGmailに入ります。英語名を入れておくと、ボタン1つで作れます）
3. 「ログインを発行」を押す
4. **仮パスワード** が1回だけ表示されます。閉じると二度と見られません。
   - 画面のQRを本人のスマホのカメラで読んでもらうと、ログイン画面がメールアドレス入りで開きます
   - LINE・メールで送るときは、メールアドレスと仮パスワードを **別々のメッセージ** にしてください
5. 「本人に伝えました（閉じる）」を押す

状態は「未発行 → 招待済み → ログイン可」と変わります。
「招待済み」＝まだ本人が最初のログイン（自分のパスワードへの変更）をしていない状態です。

> 招待メール（Supabase がメールを送る方法）は、Supabase 標準のメールだと1時間に数通しか送れません。そのため、ふだんは仮パスワードの方法を使ってください。

---

## スタッフに伝えること

1. QRを読む（またはもらったURLを開く）
2. メールアドレスと仮パスワードでログイン
3. 「自分のパスワードを決めてください」の画面で、10文字以上の自分だけのパスワードを決める
   （誕生日・電話番号・店の名前だけ、は避ける。スマホの「パスワードを保存」を使うと楽）
4. ホーム画面に追加する（下）

### スマホのホーム画面に追加する

- **iPhone（Safari）**：ログイン画面を開く → 下の共有ボタン（□に↑）→「ホーム画面に追加」→「追加」
  緑の「台帳」アイコンができ、アプリのように開けます
- **Android（Chrome）**：右上の︙ →「ホーム画面に追加」

---

## パスワードを忘れたとき

設定 → スタッフ → その人 →「パスワードを再設定」。新しい仮パスワードが表示されます（その人が今ログインしている端末はログアウトされます）。

## 一時的に使えなくしたいとき

「ログインを止める」→ すぐログインできなくなります（データは消えません）。戻すときは「再開」（オーナーだけ）。

---

## 退職したとき

設定 → スタッフ → その人 →「退職」→「保存する」。これだけで：

- 予約台帳・シフト・会計・ネット予約に出なくなる
- **ログインも自動で止まる**（今ログインしている端末も使えなくなる）
- データ（お客様・売上）はもう見られない
- 過去の予約・売上・カルテには名前が残る

もし赤い「⚠ ログインは止まっていません」が出たら（サーバの設定がまだの時など）、
Supabase の管理画面 → **Authentication → Users** → その人のメールを選ぶ → **Ban user** で止めてください。
（その場合でも、退職にした時点でデータは見られなくなっています。）

---

## 決まりごと（安全のため）

- 自分のログインは、この画面では止めたり再設定したりできません（自分を締め出さないように）
- 店長はオーナーのログインを止められません。発行・再設定・再開はオーナーだけ
- 発行・再設定は会社ごとに1時間10回まで
- 操作はすべて記録されます（設定 → スタッフ の一番下「ログインの操作の記録」）。パスワードは記録されません
- 仮パスワードはどこにも保存されません。表示されたときにだけ伝えてください
