# LINE連携の設定手順（店舗ごと）

この手順で、店舗の LINE公式アカウントとこのアプリをつなぎます。つないだあとも、**「LINE連携を使う」をオンにするまで、お客様には何も届きません**。前日確認・再来案内・自動のお礼も、1つずつオンにしたものだけが動きます。

## 0. 先に済ませておくこと（1回だけ）

- DB更新：Supabase の SQL エディタで **0014_security_checkout.sql → 0015_line.sql** の順に流す（0014 が無いと 0015 は止まります）。
- Vercel の環境変数（Settings → Environment Variables）
  - `SUPABASE_SERVICE_ROLE_KEY`：HPB取り込みで設定済みならそのまま
  - `CRON_SECRET`：自動送信の合言葉。英数字の長い文字（例：パスワード生成で40文字）。Vercel Cron がこれを付けて呼びます
  - （任意）`APP_BASE_URL`：予約ページのURLの頭（例 `https://salon-app-alpha-seven.vercel.app`）。空なら Vercel の本番URLを使います
- 設定＞店舗・ネット予約 で「予約ページのURLの名前」を入れておく（例 kokage-gotanda）

## 1. LINE公式アカウントを作る（店舗ごと）

1. https://entry.line.biz/ から店舗ごとに LINE公式アカウントを作る（お客様用。スタッフ連絡用の「Claudeアシスタント」とは**別**にする）。
2. 箱崎のようにまだ無い店舗は新しく作る。

## 2. Messaging API を使えるようにする

1. LINE Official Account Manager（https://manager.line.biz/）→ 設定 → Messaging API →「Messaging APIを利用する」。
2. 「プロバイダー」を選ぶ。**全部の店舗で同じプロバイダー**にする（LINE のユーザーIDがそろい、あとで LIFF とつながります）。
3. 応答設定：「Webhook」をオン、「応答メッセージ」はオフ（LINE側の自動応答と二重にならないように）。あいさつメッセージは使ってかまいません。

## 3. チャネルの情報を出してアプリに貼る

LINE Developers（https://developers.line.biz/console/）→ プロバイダー → 店舗の Messaging API チャネル

| アプリの欄 | LINE Developers のどこ |
|---|---|
| Messaging API のチャネルID | チャネル基本設定 → チャネルID（数字） |
| チャネルシークレット | チャネル基本設定 → チャネルシークレット（英数字32文字） |
| チャネルアクセストークン（長期） | Messaging API設定 → チャネルアクセストークン（長期）→「発行」 |

アプリ：設定 → **LINE連携** → 「1. LINE公式アカウントの情報」に貼り、**「秘密を保存」**。
- 秘密の2つは**書くだけ**です。保存したあとは画面に出ません（サーバだけが使います）。変えるときは新しい値を入れて保存し直します。
- 「設定と文面を保存」でチャネルIDも保存します。

## 4. Webhook URL を LINE に貼る

1. アプリの「2. LINE側に貼るURL」の **Webhook URL** をコピー（`https://…/api/line/webhook/<店舗ID>`）。
2. LINE Developers → Messaging API設定 → Webhook URL に貼る →「更新」→「検証」で「成功」を確認。
3. 「Webhookの利用」をオン。

## 5. LIFF を作る（LINE の中で予約ページを開く・会計のQRで連携する）

1. LINE Developers → 同じプロバイダー →「新規チャネル作成」→ **LINEログイン**（アプリタイプ：ウェブアプリ）。
2. そのチャネルの **LIFF** タブ →「追加」
   - サイズ：Full
   - エンドポイントURL：アプリの「LIFF のエンドポイントURL」（`https://…/r/<URL名>?liff=1`）
   - Scope：openid・profile にチェック
   - 友だち追加オプション：On（Aggressive）がおすすめ
3. できた **LIFF ID**（`1234567890-AbCdEfGh` の形）と、LINEログインの**チャネルID** をアプリに貼って保存。
4. LINEログインのチャネルを「公開」にする（開発中のままだと、お客様が開けません）。
5. リッチメニュー「予約する」のリンクに、アプリに出る `https://liff.line.me/<LIFF ID>` を貼る。

## 6. 試す → オンにする

1. 「接続テスト」→「つながりました：（アカウント名）」と出ればOK。
2. 自分のスマホで店舗の LINE を友だち追加して、何か1通送る → アプリの **LINE受信箱** に出る →「これは自分」を押す（オーナーだけ）。
3. 設定＞LINE連携 →「文面」で文面を確かめ、**「自分に試し送信」**。自分の LINE に届くか見る。
4. 問題なければ **「LINE連携を使う」をオン** → 前日確認 → 再来案内 → 自動のお礼 の順に、1つずつオンにする。

## 毎日の動き

- **前日確認**：毎日18時台に、明日の予約があって LINE がつながっているお客様へ送ります。ボタン「予定どおり伺います」「変更したい」。押された結果は予約台帳に ✓ ／ ？ で出ます。「変更したい」は台帳の「お知らせ」にも出ます。
- **再来案内**：最後の来店から、メニューごとの日数（ヘッドスパ45日・育毛30日・まつげパーマ42日・マツエク24日。設定＞メニューで変えられる）を過ぎて、次の予約が無い方へ1回だけ。日数を過ぎて30日のあいだだけ送ります（オンにした日に昔のお客様へ一斉に送らないため）。「空き率の高いときだけ」も選べます。
- **お客様の LINE をつなぐ**
  - LINE の中で予約ページを開いて予約した方 → 自動でつながる
  - HPB・電話の方 → 会計の画面・カルテの「LINEでお知らせ（QR）」を見せて読んでもらう（QRは30分・1回だけ）
- **止める**：お客様がトークで「配信停止」と送る／ブロックする／カルテの「お知らせを止める」。止めた方には送りません。
- **返信**：お客様からのメッセージは LINE受信箱 に出ます。返事は LINE Official Account Manager（スマホのLINE公式アカウントアプリ）のチャットで。返したら「対応済み」。

## 自動送信の回数（Vercel の決まり）

- `vercel.json` の自動送信は **1日1回（日本時間18時台）**。Vercel の無料（Hobby）プランは1日1回までで、時刻も1時間の中で前後します。
- 前日確認を18時より後にしたい・再来案内を昼に送りたいときは、Vercel を Pro にして `vercel.json` の `"schedule"` を `"*/15 * * * *"`（15分ごと）に変えるか、外部の cron サービスから `https://…/api/line/cron` を `Authorization: Bearer <CRON_SECRET>` 付きで呼んでください。送る時刻の設定（設定＞LINE連携）は「その時刻より後の最初の実行」で送ります。夜（前日確認は21時以降・再来案内は20時以降）は送りません。

## 料金（要確認）

LINE公式アカウントの月額と通数（2025年9月の LINE ヤフー for Business の記事より。**必ず最新の料金ページで確認してください**：https://www.lycbiz.com/jp/service/line-official-account/plan/ ）

| プラン | 月額（税別） | 無料の通数/月 | 超えたら |
|---|---|---|---|
| コミュニケーション | 0円 | 200通 | 送れない |
| ライト | 5,000円 | 5,000通 | 送れない |
| スタンダード | 15,000円 | 30,000通 | 追加で送れる（1通 最大3円） |

- 前日確認・再来案内・試し送信は**通数に数えます**（push）。ボタンを押した人への返事・自動のお礼は**数えません**（応答＝Reply）。要確認。
- 目安：月100人来店の店で、前日確認100通＋再来案内100〜200通＝無料の200通を超えるので、ライトプランが必要になりそう。
- アプリの「月の通数」にプランの上限を入れてください。80%で注意、100%で再来案内を止めます（前日確認は送ります。LINE側の上限に当たると失敗になります）。

## 安全のための決まり

- 最初は全部オフ。オンにした店舗・オンにした種類だけ送ります。
- 秘密はサーバだけが読みます（画面・ブラウザ・ログには出しません）。
- Webhook は LINE の署名（X-Line-Signature）を確かめてから処理します。
- 同じ予約の前日確認・同じ回の再来案内は1回だけ。送信には LINE の再送キーを付けるので、やり直しても二重に届きません。
